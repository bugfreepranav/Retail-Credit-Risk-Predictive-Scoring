# Dataset Setup

This project uses the Home Credit Default Risk dataset.

The raw CSV files are not included in this repository because of their large size.

Download the dataset from Kaggle and place the extracted CSV files inside this directory.

Expected files include:

- application_train.csv
- application_test.csv
- bureau.csv
- bureau_balance.csv
- credit_card_balance.csv
- installments_payments.csv
- POS_CASH_balance.csv
- previous_application.csv

The notebook expects the dataset at:

`data/`
